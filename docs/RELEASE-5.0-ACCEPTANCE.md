# TeachApp 5.0 — приёмка кандидата

Не выпускать стабильную версию, пока обязательные проверки не подтверждены. 5.0.0-rc.1 — кандидат, не заявление о завершённой приёмке.

## Автоматические проверки

- npm test; npm run validate; npm run test:browser; WebKit workflow.
- Синтетические данные: назначения нормативов, сохранение в IndexedDB, полная и выборочная копии, изоляция областей.
- Событийный матч: счёт, отмена, конец партии, итог, переход к следующей встрече, отсутствие внутренних идентификаторов и медицинских данных.
- Публичный интерфейс: 320/390/1280 px, темы, вкладки, Forzik/GitHub, обновление без перезагрузки.
- Старые версии копий восстанавливаются штатным способом. Копии с новыми назначениями открывать в текущей или более новой версии; не откатывать приложение с удалением данных.

## Ручная приёмка владельцем на тестовой команде

1. Создать защищённую резервную копию, обновить PWA без очистки хранилища. Проверить оценки, нормативы, классы, составы, черновики, архивы.
2. iPhone Safari и установленная PWA: открыть урок, проверить фактическую явку, ограничения, класс/пол нормативов. Назначить тестовый норматив, проверить сроки, экспорт Word/Excel.
3. Запустить синтетический матч, открыть постоянную зрительскую ссылку на другом устройстве без аккаунта. Проверить счёт, отмену, переход партии, окончание. Проверить отсутствие закрытых данных в публичной проекции.
4. Отключить сеть тренера, продолжить тестовый матч, убедиться в предупреждении зрителя и восстановлении счёта. Проверить, что новая версия не требует повторного создания Firebase-проекта.
5. Удалить тестовые данные и снять тестовую страницу с публикации. Реальные данные не отправлять в тестовый репозиторий.

## Отложенные архитектурные задачи

Несколько уроков одного класса за день требуют отдельной миграции правил идентификации уроков и проверки журнала, расписания, отметок, посещаемости, нормативов, архивов, экспорта и синхронизации. В этой версии модель не меняется: безопасность накопленной базы важнее формального номера релиза. Полная регистрация всех касаний также не включена; выводы работают только по отмеченным событиям. Не расширять публикацию школьных данных на Firebase. Cloudflare остаётся ручным.

## Приёмка визуального релиза 5.0

- Проверить выразительные/сдержанные/выключенные анимации и системное уменьшение движения.
- Проверить быстрые повторные очки, отмену, смену расстановки и интерактивный радар. Эффекты не должны блокировать управление.
- Проверить настройки, карточки, графики, календарь и зрительский портал при ширинах 320/390/1280 px. Сохранить доступность и возможность работы без анимаций.
- Публичная конфигурация Firebase и схема IndexedDB не изменены. Не использовать данные реальных учеников при приёмке.

Версия 5.0.0 визуального релиза готовится после автоматической приёмки. Физический iPhone и настоящая тестовая трансляция остаются отдельной ручной проверкой владельца; не считать их пройденными по результатам эмуляции.
