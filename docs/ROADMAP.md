# TeachApp — актуальный план развития

Приоритет обновлён по обратной связи тренера после VolleyPoint. Выпуски небольшие, по одному этапу; офлайн, iPhone Safari/PWA, без платных API, без лишних зависимостей. Таймеры и секундомеры не входят в план. Не публиковать данные реальных учеников/игроков в репозитории. Перед merge: npm test, npm run validate, успешный CI; физический iPhone проверяется отдельно.

## 2.3.2 — расстановка по зонам
Зона 1 → выбор игрока → зона 2 и так до 6. В любой момент выбрать любую зону, очистить её, назначить свободного игрока. Не предлагать дубли или выбранного либеро. Старт предыдущей партии копируется отдельно от состава на конец партии; можно очистить. Одинаковая логика обеих команд, пресетов и прежнего режима. Проверить черновики, ограничения, сохранённые матчи и касания на iPhone.

## 2.3.3 — карточки игрока
Фильтр сезона/дат, история матчей, амплуа, присутствие на тренировках, заявка отдельно от подтверждённого выхода на площадку, сыгранные партии только при наличии данных. Результативные атаки, блоки, эйсы, ошибки по элементам, выигранные очки на подаче, серии. Различать фактические попытки и нижнюю границу по отмеченным действиям; неизвестное не заменять нулём. Сохранить историю при переименовании и архивировании. Подготовить общую модель для импорта и тестов.

## 2.3.4 — импорт протоколов
Локальный разбор текстовых PDF VolleyPoint. Сначала подтвердить формат на приложенном образце: итог, партии, индивидуальная статистика, серии подач и детали очков. Не загружать реальные PDF в GitHub и внешние сервисы; тестовые данные синтетические. Выбор нашей команды, сопоставление по имени/номеру с явным подтверждением спорных соответствий, предварительный просмотр, контроль дублей по идентификатору/хешу и параметрам матча; атомарная запись. Не строить вымышленную историю событий и знаменатели попыток; PDF без текстового слоя не угадывать, предусмотреть ручную корректировку. Оценить локальную зависимость PDF-парсера, лицензию, размер офлайн-кеша; подключать только при необходимости.

## 2.3.5 — тренировочные тесты
Подача, приём, атака, передача и пользовательские тесты: дата, упражнение, попытки, успехи, ошибки, попадания в цель; проверка согласованности чисел. Физподготовка: прыжок, высота съёма, ОФП/СФП, единицы измерения, история. Тесты не смешивать с матчами и школьными оценками. Ввод индивидуально и по команде; ограничения и сохранение без автоматического допуска.

## 2.3.6 — сезонная аналитика
Фильтры по сезону, периоду, амплуа, источнику, графики и динамика, сравнение игроков и элементов. Лучший подающий, эйсы, результативность, стабильность и прогресс: показывать выборку, объём попыток и полноту фиксации; минимальные пороги сравнения; без попыток не считать проценты и не присваивать «безошибочность». Выводы объяснимые, без платного ИИ, не выдавать рейтинг за медицинскую оценку. Возможная рекомендация стартовой шестёрки с учётом ролей и данных — отдельное решение тренера, без автоматического назначения. Не использовать несопоставимые тесты для сравнения.

Поздние улучшения матча: полноэкранное табло, динамика счёта, санкции, смена сторон, правила замен/либеро обеих команд, режим только счёта — после приоритетной аналитики.

## 2.4.0–2.7.0 — итоговая приёмка
Библиотека, конспекты и шаблоны тренировок; архив и перевод классов только после завершения года, резервная копия перед переводом; календарь и локальные уведомления, ICS; турниры, сетки, результаты, таблица и CSV. Офлайн, без внешних API. На физическом iPhone вручную проверить все четыре экрана, сохранение после перезапуска, обновление без удаления данных, экспорт и восстановление тестовой копии. Фоновые push не гарантируются. Турнирная таблица использует описанные в интерфейсе правила, не официальный регламент любой федерации.
