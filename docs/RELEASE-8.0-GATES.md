# TeachApp: контрольная интеграция до 8.0

Этот PR объединяет первые контрольные пакеты 6.0.1–7.3. Версия приложения остаётся 6.0.1-кандидат; ни один незавершённый пакет не объявляется релизом.

| Область | Контрольный пакет | Условие полного завершения |
| --- | --- | --- |
| 6.1 | Экранная блокировка, изолированное LAB-хранилище с AES-GCM, CAS ревизий, сменой пароля и проверяемой переносимой копией | Интеграция шифрования действующей базы, ключи, восстановление, обратимая миграция и физическая приёмка |
| 6.2 | Строгий декодер ответов и неопределённый PUT | Production Delta, барьер версии, резервное копирование и обратимая миграция |
| 6.3 | Плотность журнала, атомарная вставка TSV, массовый выбор и CAS-редактирование обычных оценок | Физическая проверка мобильного журнала и клавиатуры |
| 6.4 | Сценарий оценок, многолетняя аналитика по параллелям, сравнительный отчёт по годам и плану сезона (Word/Excel/печать) | Проверка документов на физических устройствах и реальных архивах |
| 6.5 | Измеренная шкала, попытки и качество по проверенным PRO-розыгрышам | Приёмка ввода и сравнения на реальном матче |
| 6.6 | Видео с точным временным шагом, выполнение целей этапов сезона и учёт дней вне этапов | Полный видеоанализ, навыки, приёмка периодизации |
| 6.7 | Выявление конфликтов, V3-кандидат с уникальным ID и CAS | Миграция, переключение клиента и развёртывание архива/медиа |
| 6.8 | Настройки фото/эмблемы, до шести редактируемых текстовых/графических слоёв | Проверка экспорта и удобства на устройствах, расширенный редактор изображений |
| 6.9 | Индексы аналитики | Полная декомпозиция, бюджеты и устройство |
| 7.0–7.2 | LAB: приглашения, ответы, ассистент, workspace-scoped recovery | Production identity, эксплуатационное восстановление, независимая авторизация, юридическая и эксплуатационная приёмка |
| 7.3 | Напоминания в открытом календаре | Фоновая доставка, управление подписками и реальный device test |
| 8.0 | Интеграционный тест | Все перечисленные условия и приёмка на устройствах |

## Автоматическая проверка

Проверить точный SHA этого PR: npm test, npm run validate, Chromium, WebKit (реальный upgrade), синтетические Cloudflare/Delta/Platform/Firebase, отсутствие производственных deploy. Никаких личных данных в тестах.

## Устройства и миграции

Перед установкой на рабочие устройства сохранить зашифрованные независимые копии. Проверить открытие офлайн, журнал, синхронизацию, LIVE, импорт/экспорт, уведомления и восстановление на PC/iPhone. Не активировать LAB на рабочих данных. Отдельно проверить конфигурацию и секреты каждого сервера, staged migration и откат; никаких изменений Firebase/Worker без проверенного плана. Старые импортированные .ics с UID, содержащим дату, могут потребовать удаления дубля при повторном импорте. События из экспортированного календаря не обновляются автоматически.
