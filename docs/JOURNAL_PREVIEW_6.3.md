# Журнал 6.3 — согласованный предпросмотр массового ввода

В интерфейсе TSV и выбора ячеек теперь фиксируется контекст каждого урока: класс, дата, номер/время, тема и её название, эффективная нагрузка (в том числе унаследованная от темы), состояние проведения и примечание. Тема видна в предпросмотре. Оба сценария требуют подтверждённый снимок урока; внутри общей readwrite-транзакции сравнивается актуальный снимок каждого урока. При изменении тема/нагрузка/состояние требуют повторного предпросмотра; весь блок и история оценок остаются без изменений. Существующие проверки ученика, даты, отметки, ограничений, освобождений и участия сохранены. Копия массива подтверждённых записей создаётся до первой асинхронной операции, поэтому последующая мутация вызывающего массива не меняет план.

Низкоуровневый API сохраняет совместимость с прежними вызовами без снимка; UI явно требует его через requireLessonSnapshot. Регрессии проверяют изменение темы, нагрузки, состояния, неполный план и изменение массива после запуска записи. Физический ввод на iPhone и настольной клавиатуре остаётся необходимой частью приёмки 6.3.


## Клавиатурный выбор ячеек

Один таб-стоп для ячеек отметок; стрелки перемещают фокус в пределах видимых учеников и уроков, Home/End — начало/конец строки, Ctrl/⌘+Home/End — границы видимой матрицы. Enter/Space открывают отметку либо переключают выбор в явном режиме «Выбрать ячейки». Shift+стрелки и Shift+клик заменяют выбор прямоугольником от якоря. Максимум 500 ячеек, при превышении старый выбор сохраняется. Escape отменяет режим выбора; изменение поиска очищает выбор, скрытые строки и итоговые столбцы недоступны для диапазона. Все изменения оценок по-прежнему требуют предпросмотра, подтверждения и проверок транзакции. Тесты: чистые функции координат, браузерный сценарий большой таблицы и фильтра. Физическая клавиатура и VoiceOver ещё не проверены.
