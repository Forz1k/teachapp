# Проверка сохранённой защищённой копии

В настройках → резервная копия можно выбрать сохранённый защищённый JSON-файл и открыть его отдельной операцией проверки. Не выполняется восстановление, запись даты копии, экспорт или сеть. Файл расшифровывается и проходит штатную проверку структуры/связей; выборочная копия и локальные sync checkpoints отклоняются. При текущем backupVersion переносимые записи сравниваются с единым текущим снимком по ID и содержимому, независимо от порядка ключей/строк. Исключены только lastBackupAt и backupReminderAfter записи settings (их меняет подтверждение экспорта). Другие изменения дают количество отличающихся разделов. Прежний формат проверяется на читаемость, но не объявляется эквивалентным. Вывод только агрегатный, без имён, записей, хешей и паролей. Скрытие/раскрытие экрана или pagehide инвалидирует незавершённый результат. Это проверка файла и наблюдаемого снимка, не физическая проверка восстановления, не гарантия сохранности внешнего носителя и не разрешение на миграцию. Для полноценной приёмки необходим отдельный профиль устройства и проверенный откат.
