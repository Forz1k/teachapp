# Карта TeachApp

`index.html` подключает локальный SheetJS, стили и модуль `js/app.js`. Приложение загружает состояние через `store.load()`, выбирает экран и подписывается на изменения. Экраны в `js/screens/` обслуживают журнал, быстрый ввод на уроке, классы, месячные отметки, освобождения, расписание, КТП и настройки. Общие шторки, подтверждения и скачивание файлов находятся в `ui.js`, оформление для iPhone — в `css/app.css`.

`model.js` содержит вычисления без DOM и IndexedDB: локальные календарные даты, интервалы, оценки, освобождения, расчёт расписания с заменами. `store.js` связывает модель и базу, хранит массивы в памяти и вызывает подписчиков после изменений. `export.js` строит матрицы из состояния, читает и записывает таблицы, вызывает методы хранилища при импорте.

## Локальные данные

База teachapp, версия схемы 2. Первичный ключ всех записей — id. Классы и ученики связаны через classId. Уроки индексируются по классу и дате. У оценки уникальна пара lessonId/studentId, у месячной записи — studentId/year/month. Освобождения индексируются по ученику и дате начала. КТП содержит classIds, темы — ktpId и ktpOrder. Недельный шаблон schedule использует weekday/slot, правки scheduleOverrides привязаны к дате. Настройки находятся в meta.

Для изменения схемы повысить DB_VERSION и добавить последовательный обработчик в migrations в db.js. Все шаги выполняются в транзакции обновления IndexedDB. Резервная копия формата 1 содержит объект data по именам хранилищ. Версии формата, схемы и приложения независимы.

## Запуск и выпуск

Node.js 24, npm ci. Запуск через npm start (Python, localhost:8099). Для тестирования отдельного файла использовать node --test tests/имя.test.mjs, перед выпуском — npm test и npm run validate. CI повторяет проверки при push и pull request.

Источник версии — package.json. Добавить раздел версии в CHANGELOG.md и выполнить npm run release -- X.Y.Z. Команда обновляет lock-файл, модуль интерфейса и константу SW. При добавлении клиентского модуля включить его в PRECACHE. Пути относительны для размещения в подпапке. Сервер и внешние CDN для работы приложения не требуются.

## Точки риска для следующих этапов

Экспорт месячных строк и фильтр периода относятся к этапу 2. Каскады освобождений — к этапу 5. Восстановление копии требует проверки до очистки базы (этап 6). Текущий SW допускает частично заполненный кеш и удаляет сторонние кеши (этап 7). Подписка приложения перерисовывает экран после изменения состояния (этап 8).
