# TeachApp 2.0 — чек-лист выпуска и ручного тестирования

Автоматические проверки: npm ci, npm test, npm run validate. В CI проверить именно SHA релиза и публикацию Pages. Тесты используют fake-indexeddb и jsdom; они не доказывают работу Safari или конкретного физического устройства.

## Ручная проверка (на отдельном профиле / демо-данных)

- Чистая установка: HTTPS/localhost, запуск и демо-данные, сохранение и перезапуск.
- PWA: дождаться установки SW, отключить сеть, открыть все разделы; обновление со старой версии, отказ при неполном кеше и сохранность IndexedDB. Не очищать рабочую базу.
- Резервные копии: обычная, защищённая, неверный пароль, повреждённый файл, восстановление старых форматов 1–4, сохранение школьной и тренерской истории.
- Журнал: оценки, Н, ОСВ вместе с Н, отмена, горизонтальная и вертикальная прокрутка, быстрый ввод.
- Расписание: перенос/отмена, каникулы, КТП и подтверждение тегов, предупреждения.
- Участие: родительская записка не превращается автоматически в полное ОСВ; документальное освобождение; сохранение ручной оценки.
- Ограничения: группа, индивидуальные сроки, совпадение с темой и нормативом, запрет обычной сдачи при противопоказании, без автоматической отрицательной оценки.
- Нормативы: шкала, результат, история, перенос только по подтверждению в свободную ячейку.
- Волейбол: команды, тренировки, посещаемость, партии, частичная статистика, CSV без ограничений, отсутствие передачи школьных данных.
- Аналитика: будущие и пустые клетки не считаются явкой, итоги только завершённого периода, отдельный отчёт, печать, предупреждения только по явному выбору.
- Защита: быстрый экран скрытия, восстановление фокуса, срок хранения, предварительный просмотр, сохранение активных сведений, отсутствие паролей в базе, отсутствие чувствительных полей в обычной ведомости.
- iPhone Safari: установка на экран Домой, портрет/альбом, safe area, прокрутка, шторки, клавиатура, тёмная тема, сохранение файлов, офлайн и обновление.
- Версия 2.0.0 на экране и в package.json/lock/SW/CHANGELOG.

Физический iPhone и браузерная проверка полного сценария релиза не подтверждены автоматическими тестами; отметить результаты после фактического выполнения.
