# Проверка изоляции LAB-конфигураций

`npm run validate` проверяет три синтетических Wrangler-конфига и Firebase emulator config. Только известные имена, entrypoint, локальные Durable Object bindings и ожидаемая миграция; никаких routes, preview URLs, workers.dev, env, vars, внешних bindings или observability. Конфиги используют строгий JSON-поднабор JSONC. Production beta-конфиг читается только для проверки отсутствия коллизии имени. Firebase emulators привязаны к 127.0.0.1, UI отключён, путь rules фиксирован. Новые поля требуют осознанного изменения allowlist и тестов.

Это статическая проверка репозитория, а не проверка реального облачного аккаунта, секретов, CLI override или сетевого доступа. Не запускает deploy, не меняет production rules, не подтверждает готовность миграции. Реальные маршруты и права необходимо независимо проверять перед публикацией.
