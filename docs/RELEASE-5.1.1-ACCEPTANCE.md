# TeachApp 5.1.1 — приёмка кандидата

Статус: **5.1.1-rc.1, не опубликован**. Исходная публичная версия 5.1.0 (main `de8b0991411cb85fb2aaf0c739e966552bc98077`). PR [#94](https://github.com/Forz1k/teachapp/pull/94). Переход с кандидата на стабильный номер требует нового согласованного изменения версий и повторной проверки.

## Совместимость и границы выпуска

| Компонент | Что сохраняется / меняется |
|---|---|
| IndexedDB | v10 → v10; без миграции схемы |
| Резервная копия | v21 → v21, существующие старые форматы поддерживаются валидатором |
| Синхронизация | Существующие TAP1/TAC1, полный зашифрованный снимок и CAS; обновить все устройства до обмена новыми видами записей |
| Доверенные устройства | v2 требует отдельно настроенного Worker; не переключается автоматически |
| Service Worker | Новый cache namespace версии, обновление по кнопке «Обновить» |
| Firebase | Текущие правила не меняются при статическом выпуске; расширенный архив требует отдельной согласованной публикации |
| Delta / Platform | Изолированные синтетические LAB; не использовать для реальных данных |
| Studio | Цвета, подпись и формат хранятся локально, не входят в переносимую копию |

Номер копии сам по себе не гарантирует обратную совместимость: новые типы рабочих записей могут не распознаваться старым приложением. Не откатывать путём удаления данных сайта.

## Автоматическая приёмка

- [ ] npm test, validate, оба CI-прогона, измерения на синтетической базе, Chromium и WebKit.
- [ ] Реальное обновление в WebKit на одном origin: исходный код 5.1.0 из зафиксированного git-коммита, настоящий Service Worker, сохранённые записи школы/тренера, зашифрованная контрольная точка, подтверждение обновления через баннер, сверка содержимого IndexedDB, версия кеша, офлайн-перезагрузка.
- [ ] Проверка восстановления старой защищённой копии в независимом новом контексте и повторной работы с незавершённым матчем.
- [ ] Проверки Cloudflare, Firebase emulator, Delta LAB, Platform LAB только на синтетических данных. Отсутствие production deployment.

## Перед обновлением на устройствах

1. На **каждом** устройстве завершить текущий урок и активную запись матча, закрыть остальные вкладки TeachApp. Не удалять незавершённые матчи ради обновления.
2. Настройки → Резервная копия: создать защищённую полную копию. Сохранить файлы ПК и телефона отдельно, проверить наличие и пароль. Не переносить ключи доступа в обычный архив. При v2 при необходимости создать отдельный защищённый файл ключей восстановления.
3. Если синхронизация использовалась, сравнить ревизии и разрешить конфликты, особенно удаления. Проверить, что независимые локальные изменения не потеряны. Не синхронизировать реальные данные через экспериментальные серверы.
4. После официального выпуска открыть PWA с интернетом, дождаться баннера «Доступна новая версия TeachApp», нажать «Обновить». Если баннера нет, закрыть и заново открыть приложение, проверить номер в настройках. Не очищать кеш/данные сайта, не удалять PWA.
5. Повторить на втором устройстве **до дальнейшего обмена**. Проверить номер версии, локальные классы, оценки, нормативы, тренировки и историю матчей.

## Если что-то пошло не так

Не удалять приложение, не очищать сайт и не повторять запись вслепую. Остановить обмен, сохранить отдельную защищённую копию текущего состояния. При прерванном PUT сравнить ревизии: сервер мог принять пакет, даже если локальная запись остановлена. Не восстанавливать старую копию поверх рабочей базы без сравнения — восстановление заменяет базу и исключает прежние контрольные точки. Отзыв ключа доступа не отзывает уже скачанные данные и не меняет ключ шифрования.
