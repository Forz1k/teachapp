Журнал учителя физкультуры

Офлайн-PWA на чистом HTML/CSS/JS. Скриншоты сняты в headless-браузере на ширине 390 px (iPhone, портрет) с демонстрационными данными: 3 класса, 90 учеников, 66 уроков, 1 343 отметки.

Как переснять: поднимите сервер (npm start), выполните npm run snapshot, затем npm run shots. Файл shots/preview.html заполняет состояние приложения напрямую из seed.json — так снимки не зависят от того, успела ли IndexedDB инициализироваться в headless-режиме.
